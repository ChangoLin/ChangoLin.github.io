This demo contains 28 resized WebP frames derived from the existing repository
copy of the asset. The original credit file identifies the artist as Segel T:
https://www.facebook.com/Segel.T

Demo note: both fighters and all generated classes use this knight as a visual
placeholder. The blue fighter is distinguished with a CSS color treatment.
