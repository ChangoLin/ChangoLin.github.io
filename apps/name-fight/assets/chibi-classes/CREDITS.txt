The source page states that the pack contains ten 16x16 medieval character
classes with male/female variants, attacking, walking, running, jumping,
landing, injured, and death animations. It identifies the asset license as
CC0 and states that no generative AI was used.

This distribution contains twelve 192x160 WebP atlases derived from the source
PNG. Each atlas contains only the idle pose plus the run, attack, injured, and
death frames used by the default Name Fight chibi experience. Horizontal mirroring is
performed at runtime so opponents face one another.
